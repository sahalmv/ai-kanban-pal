# Project Pal

Build a modern Kanban board app inspired by the attached Scopeboard design with a 3-column workflow (To Do, In Progress, Done), drag-and-drop cards, priority badges, tags, and member avatars. Include an integrated AI co-pilot chat that can answer project questions and directly create, update, or move tasks on the board. Enable Lovable Cloud with user authentication and database persistence so boards and tasks are saved securely to user accounts.

This project was built with [Lovable](https://lovable.dev).
